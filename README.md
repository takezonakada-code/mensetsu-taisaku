# 面接準備

転職の模擬面接に向けて、面接シートの各社タブ（C列：回答①、D列：深掘り）を埋めるためのスマホ向けサイト。

- 会社ごと（CyberZ／ワンスター／ビタブリッド／博報堂DY ONE）に、その会社の求める人物像・面接で見ているポイント・業務内容に合わせて細かく分けた質問を出す
- 声（音声認識）でも文字でも答えられる
- 回答はブラウザの中（localStorage）にだけ保存され、どこにも送信されない
- 「回答を送る」でまとめてコピー・共有・ファイル保存できる

## 構成

| ファイル | 中身 |
|---|---|
| `index.html` / `style.css` / `app.js` | 画面 |
| `data.js` | 質問データ（`tools/build-data.py` で作る） |
| `tools/build-data.py` | 会社ごとの質問 JSON を `data.js` にまとめ、公開してはいけない語が残っていないか確かめる |

音声入力は Web Speech API（iPhone の Safari、Android の Chrome で動作）。使えない端末では、キーボードのマイクで入力できる。
